# 排版元素

本頁列出手冊常用的排版元素, 每個範例下方附有對應的 Markdown 寫法.

## 提示框

::: info 說明
補充資訊, 讀者可以略過.
:::

::: tip 建議
建議做法或小技巧.
:::

::: warning 注意
需要讀者留意的事項.
:::

::: danger 警告
操作錯誤會造成損失的步驟.
:::

```md
::: tip 建議
建議做法或小技巧.
:::
```

## 表格

| 欄位 | 說明 | 必填 |
|---|---|---|
| 名稱 | 項目名稱 | 是 |
| 負責人 | 負責處理的同仁 | 是 |
| 備註 | 其他補充 | 否 |

```md
| 欄位 | 說明 | 必填 |
|---|---|---|
| 名稱 | 項目名稱 | 是 |
```

## 程式碼區塊

程式碼區塊會自動上色, 右上角有複製按鈕.

```bash
# 查詢磁碟使用量
df -h
```

指定行數可以標示重點:

```python{2}
def greet(name):
    return f"你好, {name}"
```

## 可折疊區塊

::: details 點這裡展開
折疊區塊適合放較長的補充說明或範例輸出.
:::

```md
::: details 點這裡展開
內容
:::
```

## 連結與圖片

站內連結用相對路徑, 例如回到[手冊簡介](../guide/). 圖片放在 `docs/public/` 資料夾, 用 `![說明](/圖片檔名.png)` 引用.
