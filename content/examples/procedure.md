# 作業程序範例: 新進同仁設備設定

本頁示範標準作業程序 (SOP) 的寫法: 先寫目的與適用範圍, 再依順序列出步驟, 最後附檢核清單. 內容僅為示意, 正式使用時請替換.

## 目的與適用範圍

本程序說明新進同仁到職第一天的筆電設定步驟, 適用於所有到職同仁.

| 項目 | 內容 |
|---|---|
| 負責人 | IT 管理員 |
| 所需時間 | 約 1 小時 |
| 前置條件 | 已建立公司帳號 |

## 作業步驟

### 步驟 1: 開機與登入

1. 開啟筆電, 依畫面指示選擇語言與地區.
2. 使用公司帳號登入.
3. 首次登入時, 依指示設定新密碼.

### 步驟 2: 啟用磁碟加密

1. 開啟系統設定, 找到磁碟加密功能.
2. 啟用加密, 並將復原金鑰交給 IT 管理員保管.

::: warning 復原金鑰不可自行保存
復原金鑰遺失會導致資料無法復原, 必須由 IT 管理員統一保管.
:::

### 步驟 3: 安裝必要軟體

依職務別安裝軟體, 清單請洽 IT 管理員.

### 步驟 4: 設定多因素驗證

1. 在手機安裝驗證 App.
2. 登入帳號設定頁面, 掃描 QR Code 完成綁定.

## 完成檢核清單

- [ ] 已用公司帳號登入
- [ ] 磁碟加密已啟用, 復原金鑰已交付
- [ ] 必要軟體已安裝
- [ ] 多因素驗證已綁定
