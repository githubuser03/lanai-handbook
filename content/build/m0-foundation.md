# M0 基礎環境

::: info 本章屬性
- 等級: ● 必要
- 狀態: 撰寫中 (僅有大綱)
- 資料基準日: 2026-10-26
- 待查證: Proxmox VE 與 Proxmox Backup Server 的版本與設定步驟待依官方文件驗證
:::

**結論**: 後續每個模組都放在這一章準備的環境裡: 一台主機, 一個不對外開放的內網網段, 以及能還原的備份. 單人單機可以只用一台 Linux 或 Mac 加 Docker; 多人共用時, 改用 Proxmox VE 以 VM 劃分信任區.

**這一塊在圖上的位置**: 實體主機 Proxmox VE, 各 VM 區的邊界, 以及備份伺服器. **前置模組**: 無. **完成後的狀態**: 主機, 網段與備份都已就位, 可以開始組裝 M1.

## M0.1 兩種起點: 單機或 Proxmox VE

待撰寫要點:

- 單機: Linux 或 macOS 加 Docker, 適合里程碑 1
- Proxmox VE: 以 VM 劃分入口區, 推論區, 閘道區等信任區, 適合里程碑 2 以上
- 接觸不可信內容的元件放 VM, 不放 LXC 容器 (隔離較弱)

## M0.2 內網網段與防火牆

待撰寫要點:

- 只開放內網, 公網不做任何連接埠轉發
- 各 VM 區之間的允許連線清單 (對照組裝總覽的部署分區表)
- 管理介面放在獨立的管理網段, 並開啟雙因素驗證

## M0.3 Docker 與容器的共同設定

待撰寫要點:

- 發布連接埠時指定 127.0.0.1 或內部網路
- 映像以摘要值鎖定版本 (見 O2)
- 機密存在 .env, 權限 600

## M0.4 備份伺服器

待撰寫要點:

- Proxmox Backup Server 或 NAS, 每週備份 VM 與資料卷
- 先完成一次還原演練, 再進入 M1 (見 O1)

## M0.5 驗收測試

待撰寫要點:

- 從外部網路掃描, 確認沒有開放的連接埠
- 還原一台測試 VM, 確認備份可用
