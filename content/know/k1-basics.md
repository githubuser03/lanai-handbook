## K1.1 模型, 權重與 token

待撰寫要點:

- 模型, 權重檔, 參數量的關係
- token 保留英文, 首次出現時以一句話說明 (文字切分後的最小處理單位)
- 上下文長度與回應速度的關係
- Tokenizer: 把文字切成 token 的規則, 不在權重裡; GGUF 格式把它和權重包在同一個檔案
- 推論伺服器的工作: 載入權重, 執行 Tokenizer, 計算輸出, 提供 API
- 嵌入模型與向量: 為什麼「問自己的文件」需要另一個模型

## K1.2 推論, 微調與預訓練的差異

待撰寫要點:

- 三者的用途, 成本與硬體需求差異
- 多數讀者只需要推論, 少數需要微調, 極少數需要預訓練
- 指向 T1 的判斷流程

## K1.3 本機與雲端的取捨

待撰寫要點:

- 隱私, 成本, 品質, 維運負擔四個面向
- 不預設地端優於雲端, 說明適用情境
