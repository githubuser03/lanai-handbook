# 第 1 章 使用說明與自我檢測

::: info 本章屬性
- 等級: ● 必要
- 狀態: 可閱讀 (部分資料待核對)
- 資料基準日: 2026-10-26
- 待查證: 1.3 節的硬體查詢指令未實機驗證; 硬體等級 E, F 的規格門檻待第 7 章定義
:::

**結論**: 回答三個問題, 就能找到自己的閱讀路徑: 想做什麼, 手上是什麼硬體, 之後誰維運. 多數讀者只需要讀「必要」章節, 加上一至兩個依情境才讀的章節.

本手冊整理如何在自己的機器或機房內執行 AI 模型, 範圍涵蓋概念, 評估選擇, 架設部署, 應用擴充, 訓練微調與維運更新. 手冊不預設地端優於雲端, 也不包含法規解讀; 涉及法規的決定, 請洽法律顧問.

## 1.1 先回答三個問題

| 問題 | 選項 |
|---|---|
| 1. 想做什麼 | a. 自己用, 與模型對話 / b. 讓模型回答自己的文件 / c. 給 2 人以上共用 / d. 想訓練或微調 / e. 還在評估該不該自架 |
| 2. 手上是什麼硬體 | 見 1.3 節, 對應等級 A 至 F |
| 3. 之後誰維運 | 有人每週檢查安全公告與備份 / 沒有固定的人 |

第 3 題的答案會限制可選的架構: 沒有人固定維運時, 請只採用最小組合 (第 9.1 節), 並在第 3 章分層圖中只保留 ● 必要層.

## 1.3 硬體自我檢測

### 查出自己的規格

以下指令未實機驗證, 輸出欄位名稱會因作業系統版本而異; 若與說明不符, 以系統設定畫面為準.

| 系統 | 指令 | 看什麼 |
|---|---|---|
| Windows 或 Linux, 有 NVIDIA 顯示卡 | `nvidia-smi --query-gpu=name,memory.total,driver_version --format=csv` | 顯示卡型號, 顯示記憶體, 驅動版本 |
| macOS | `system_profiler SPHardwareDataType` | 晶片 (是否為 Apple Silicon) 與記憶體 |
| Linux | `free -h` | 系統記憶體 |
| Windows (PowerShell) | `Get-CimInstance Win32_ComputerSystem \| Select-Object TotalPhysicalMemory` | 系統記憶體 (單位為位元組) |

### 對應等級

| 等級 | 特徵 | 建議起點 |
|---|---|---|
| A | 無獨立顯示卡的筆電 | 最小組合, 桌面版介面 (第 9.4 節) |
| B | 8 至 12GB 顯示記憶體 | 最小組合 |
| C | Apple Silicon Mac, 以統一記憶體容量決定能力 | 16GB 用最小組合; 32GB 以上可考慮標準組合 |
| D | 16GB 顯示記憶體 | 標準組合 |
| E | 預算較高的單機配置 | 標準組合 (規格門檻待第 7 章定義) |
| F | 預算更高的多卡或大容量配置 | 進階組合 (須有人每週維運) |

顯示記憶體 (或統一記憶體) 比運算速度更常決定「模型跑不跑得起來」, 估算方法見第 5 章. 此對應表來自研究 1 的分級, 待以第一手報價與規格核對 (信心: 中).

## 1.4 決策者: 先看這幾頁

不需要先懂技術, 也能判斷該不該自架. 建議順序如下:

1. [一頁決策摘要](/decide/summary): 三分鐘看完結論與前提.
2. [該不該自架決策樹](/decide/should-self-host): 依資料敏感度, 使用人數與維運能力判斷.
3. [成本試算表](/decide/tco): 自己填入數字, 比較自架與雲端 API.
4. [風險自評](/decide/risk-checklist): 十個問題, 看維運前提是否成立.
5. [授權紅旗](/decide/license-flags): 對外提供服務前, 哪些授權條款要先處理.
6. [30 天 PoC 計畫](/decide/poc-30days): 用最小代價驗證, 再決定是否投入.

## 1.5 標示的讀法

| 標示 | 意義 |
|---|---|
| ● 必要 | 所有讀者都需要 |
| ○ 依情境 | 符合條件才讀, 條件寫在章首 |
| ◇ 進階或選讀 | 初階讀者可以略過 |
| 撰寫中 (僅有大綱) | 只有章節骨架, 尚無可用內容 |
| 可閱讀 (部分資料待核對) | 內容可參考, 但標示「待核對」的數字或來源尚未以第一手資料確認 |
| 已審閱 | 內容與來源經人工逐項核對 |
| 未實機驗證 | 指令依官方文件整理, 尚未在實機執行; 執行前請先在測試環境試跑 |
| 信心: 高 / 中 / 低 | 超出事實的判斷所附的信心水準; 標「推論」者為整理者推論 |

正文只寫原則與判斷流程. 版本號, CVE, 價格與基準分數一律放在[參考資料](/ref/versions), 並標示來源與資料基準日.
