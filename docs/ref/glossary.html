本頁屬性

  • 等級: 參考資料
  • 狀態: 可閱讀
  • 資料基準日: 2026-10-27
  • 實機驗證: 不適用
  • 中文譯名已以國家教育研究院樂詞網核對 (2026-10-27); 樂詞網未收錄的術語依台灣業界用法, 表中逐項註明.
  • 處理方式分三種: 有通用中文譯名者用中文, 首次出現附原文; 業界慣用英文者直接用英文; 沒有通用譯名者保留英文, 不自創譯名.
  • 新增或修改術語請開 PR, 並在說明中附上所依據的台灣用法來源.

本頁列出手冊常用的術語, 每個術語附上本手冊採用的寫法與一句說明; 各章第一次出現時另有較完整的解釋.

保留英文 ​

術語說明
token模型處理文字時切出的最小單位. 不譯為「詞元」, 因該詞為中國大陸官方定名 (來源: 世界日報 2026-03-25 報導)
KV cache推論時暫存注意力運算結果的記憶體, 讓模型不必每次重算前文
LoRA, QLoRA低秩適配微調方法: 不改動原模型的全部參數, 只訓練一小組附加參數; QLoRA 另把原模型量化, 進一步減少所需記憶體
MCPModel Context Protocol, 模型與外部工具之間的協定
PoC, scope, onboarding, roadmap, runbook業界慣用英文
GGUF, safetensors模型檔格式
開源 / 原始碼公開見授權速查: 前者指符合 OSI 定義, 後者指原始碼可看但使用有限制

常見工具與服務 ​

下列工具在多個章節出現, 此處只說明各自在架構中的角色; 授權見授權速查, 版本見版本與漏洞.

工具角色
Ollama, llama.cpp, vLLM推論伺服器: 載入模型檔, 對其他程式提供呼叫模型的 API (見 M1)
Open WebUI使用者介面: 讓使用者在瀏覽器裡和模型對話, 並管理知識庫 (見 M2)
LiteLLM模型閘道: 所有模型呼叫的統一入口, 負責轉送, 金鑰與配額 (見 M5)
Keycloak身分驗證服務: 管理帳號與群組, 讓各服務共用同一套登入 (SSO) (見 M5)
Qdrant向量庫: 存放文件段落的向量, 依意思找出相近段落 (見 M4)
n8n流程自動化平台: 依排程或事件串接各系統, 自動執行固定流程 (見 M9)
OPA政策引擎: 依事先寫好的規則判斷某個動作准不准執行 (見 M8)
LangGraph代理開發框架: 把模型, 工具與判斷步驟串成可追蹤的流程 (見 M8)
Docker容器工具: 把服務與執行環境包成映像, 在隔離的容器中執行 (見 M0)
Hugging Face模型分享網站: 多數開放權重模型從這裡下載 (見 M3)
