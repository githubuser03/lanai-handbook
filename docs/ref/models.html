模型建議 (含繁體中文) ​

本章屬性

  • 等級: 參考資料
  • 狀態: 可閱讀 (部分資料待核對)
  • 資料基準日: 2026-10-27
  • 待查證: 各等級的模型落點為依 K2 公式估算的權重大小, 未實測; 等級 E, F 的門檻沿用 K3.1 節 (整理者設計); Gemma 4 E4B 與 12B 的模型 ID 未在模型卡上確認; 各模型的繁體中文能力除 TAIDE 與 Breeze 2 外均未見官方評測; 文中的類比為整理者所寫, 不代表技術上完全等同

結論: 挑模型先看記憶體放不放得下, 再看授權, 最後才看能力. 8 至 12GB 顯示記憶體可從 8B 級模型開始; 16GB 放約 14B 級餘裕較大 (與 K3.1 節一致); 24B 至 32B 級要 24GB 以上, 其中 30B 級在 24GB 時上下文須壓低. 需要繁體中文表現時, TAIDE 與聯發創新基地的 Breeze 2 是以繁體中文資料訓練的選項, 但授權各有條件; 國際模型的模型卡多半沒有繁體中文評測, 導入前請用自己的題目實測.

依硬體等級: 先算放不放得下 ​

挑模型像搬家前量家具: 先確認放得進去, 再談好不好用. 下表把本手冊的硬體等級 (定義見使用說明與 K3.1 節) 對應到可以起步的模型. 「4 位元權重約」一欄依 K3 的算式估算: 參數量 x 4.8944 位元 / 8 (llama.cpp 以 Llama-3.1-8B 量測的 Q4_K_M 平均位元數, 套用到其他模型為近似). 這只是權重大小, 實際還要加上 KV cache 與執行環境, 所以記憶體要留餘裕 (推論, 信心: 中).

資料來源: 參數量, 授權與記憶體說明取自各模型的 Hugging Face 模型卡 (2026-10-27 擷取); 4 位元權重為整理者依上述算式推算. 等級與模型的對應為整理者推論 (信心: 中), 與 K3.1 節的估算一致: B 級放 8B 級餘裕較大, D 級放約 14B 級餘裕較大, 約 30B 以上通常放不下 16GB. E 級中約 30B 至 32B 級的模型 (權重約 18.4 至 19.6GB) 在 24GB 時已接近或超過 K2 建議的八成上限 (約 19.2GB), 上下文須壓低, 或改用 32GB 以上的配置.

由上表可見, 每升一個等級, 可選的模型大約大一倍. 等級 F 在 48GB 時可讓一個約 30B 至 35B 級的模型保留充足的上下文並服務多人; 同時常駐多個這類模型, 或跑約 70B 級, 需要 64GB 至 96GB 以上 (見 K3.1 節與 K3.4 節, 推論). 實際挑選時要再看三件事:

  • 授權: Llama, Gemma (TAIDE 沿用) 的自訂授權各有條件, 對外提供服務前請依 K4 與授權速查檢查. Apache 2.0 與 MIT 的限制最少.
  • MoE 的取捨: MoE 模型每次只啟用一小部分參數, 產生文字較快, 但權重仍要全部放進記憶體, 容量以總參數計 (見 K3.4 節).
  • 工具呼叫: 要讓模型操作工具時, 另看 K5 的 BFCL 分數; 通用小模型的多輪表現普遍偏低.

30B 至 35B 級模型的細部比較 (層數, 上下文, KV cache 用量) 見 K3.4 節; 資安用途的小型分類與檢索模型 (提示注入偵測, 個資偵測等) 見開源模型選型; 嵌入與重排序模型見 M4.

繁體中文: 模型卡有寫才算數 ​

多數國際模型以英文為主要訓練語言, 模型卡上的「支援語言」清單差異很大, 而且「支援中文」通常沒有區分簡體與繁體. 判斷繁體中文能力時, 本手冊只採用模型卡或官方文件明載的內容, 其餘以自己的題目實測為準.

以繁體中文資料訓練的模型 ​

TAIDE 是以繁體中文資料訓練的台灣模型系列, 在 Hugging Face 的 taide 組織下發布. 目前最新的對話模型是 Gemma-3-TAIDE-12b-Chat-2602, 以 google/gemma-3-12b-pt 為基底, 約 12.4B 參數, 上下文 128K; 模型卡說明以約 220 億個繁體中文 token 持續預訓練, 並在 NVIDIA H200 上訓練 1,520 GPU 小時. 輸入只接受文字. 模型卡自報 TMMLU+ 平均 58.02, 同表的 Gemma-3-12b-it 為 53.82; 台灣地理與台灣用語兩個子科目分別為 70.05 與 76.11 (來源: 模型卡自報, 2026-10-27 擷取; TMMLU+ 的讀法見基準分數).

取得方式: 模型為 gated model, 須登入 Hugging Face 並接受「(Gemma 版次)-TAIDE 模型授權條款」才能下載, 另附個人資料蒐集告知. 模型卡提供 transformers 與 vLLM 的載入範例, 建議以 bfloat16 執行. 國研院 TAIDE 網站公布的 Gemma-TAIDE 條款授予非專屬, 全球, 無償的使用授權, 條文未設使用者數或營收門檻; 散布時須附 Gemma Terms of Use 聲明並標示源自 TAIDE, 不得用於軍事或非法目的, 條款修訂於發布時立即生效. 條款要點與連結見授權速查. 同一組織也發布 Llama-3.1-TAIDE-LX-8B-Chat 等較早版本, 以及以台灣法規文本微調的嵌入模型 embeddinggemma-GTAIDE-300m-2605 (見基準分數的例子).

Breeze 2 是聯發創新基地 (MediaTek Research) 以 Llama 3.2 為基底, 以繁體中文資料持續預訓練的模型系列, 有 3B 與 8B 兩種大小, 並加入影像理解與函式呼叫能力 (來源: Breeze 2 論文 arXiv 2501.13921). 模型卡標示授權為 Llama 3.2 Community License. 要注意的是, 模型卡的載入範例須開啟 trust_remote_code, 函式呼叫還須搭配聯發創新基地的 mtkresearch 套件; 依 M3 的入庫流程, 須先審查模型倉庫附帶的程式碼才能使用. 模型卡本身沒有列出評測分數.
