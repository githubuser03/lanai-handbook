K3 硬體選購 ​

本章屬性

  • 等級: ● 必要
  • 狀態: 可閱讀 (部分資料待核對)
  • 資料基準日: 2026-10-26
  • 待查證: 等級 E, F 的規格門檻尚未定義; 各等級可跑的模型大小為依 K2 公式的估算, 未實測; 價格見硬體價格頁, 本章不寫價格

結論: 預算有限時, 先買「更大的顯示記憶體 (或統一記憶體)」, 再考慮運算速度. 記憶體決定能不能跑, 運算速度只決定跑得多快 (信心: 高).

K3.1 等級 A 至 F 的能力邊界 ​

下表依 K2的公式估算 4 位元量化模型的大致落點. 結果為推論 (信心: 中), 未實測; 實際能否執行, 還取決於上下文長度與同時使用人數.

等級記憶體條件較可能的落點 (4 位元量化, 推論)建議架構
A無獨立顯示卡, 以系統記憶體運算數十億參數以下的小模型, 速度較慢最小組合
B8 至 12GB 顯示記憶體約 8B 級模型餘裕較大; 約 14B 級須壓低上下文最小組合
CApple Silicon, 統一記憶體依記憶體容量而定, 16GB 與 32GB 以上差異大16GB 用最小組合; 32GB 以上可用標準組合
D16GB 顯示記憶體約 14B 級餘裕較大; 約 30B 以上通常放不下標準組合
E待 K3 補充門檻同 D, 並有餘裕同時載入嵌入模型標準組合
F待 K3 補充門檻較大的模型或多人同時使用進階組合 (須有人每週維運)

K3.2 記憶體優先的選購順序 ​

  1. 容量: 先確認想跑的模型加 KV cache 放得進去 (K2).
  2. 記憶體頻寬: 產生文字的速度常受記憶體頻寬限制, 而非純運算能力 (信心: 中高, 屬一般經驗).
  3. 驅動與軟體支援: Ollama 的 NVIDIA 支援要求運算能力 (compute capability) 5.0 以上, 驅動版本 550 以上; 運算能力 5.0 至 6.2 的舊卡須驅動 570 以上 (來源: Ollama 文件 GPU). AMD 與 Apple 的支援見 M1.4 節.
  4. 電源, 散熱與機殼空間: 高階顯示卡對電源供應器與機殼有要求, 購買前核對規格書 (信心: 高, 屬一般經驗).
  5. 價格時機: DRAM 與 GPU 價格波動大, 以價格頁的查價日期為準, 不憑舊資料決定.

升級既有電腦與另購整機之間, 差異主要在顯示記憶體能否增加. 若現有機器的主機板, 電源與機殼都能容納較大的顯示卡, 升級通常較省 (信心: 低, 屬推論).

K3.3 台灣通路與二手風險 ​

價格與通路資訊放在硬體價格頁, 每筆須有來源與查價日期, 目前該頁尚無內容.

購買二手顯示卡時, 建議逐項檢查 (信心: 中, 屬一般經驗):

  • [ ] 收到後立即用 nvidia-smi 確認型號與顯示記憶體容量與賣方標示相符.
  • [ ] 連續跑一段時間的推論或壓力測試, 觀察溫度與是否降頻或當機.
  • [ ] 確認保固剩餘期間與可否退換.
  • [ ] 確認驅動仍在支援清單內 (見上述 Ollama GPU 支援條件).
  • [ ] 外觀與風扇狀況, 是否有拆修痕跡.
  • [ ] 避免來源不明且價格明顯低於市場的商品.

研究 1 的分級依據 ​

等級定義來自研究 1 (待以第一手報價核對): A 無獨顯筆電; B 8 至 12GB 顯示記憶體的遊戲電腦; C Apple Silicon Mac; D 16GB 顯示卡升級; E, F 依預算區分. 預算區間見價格頁.
