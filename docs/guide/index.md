# 手冊簡介

這份手冊是文件網站的 POC, 用來確認版型、撰寫方式與發布流程是否符合需求. 確認後, 把範例內容換成正式內容即可.

## 網站的組成

畫面分成三個區塊:

| 區塊 | 位置 | 內容來源 |
|---|---|---|
| 左側選單 | 畫面左邊 | `docs/.vitepress/config.mts` 的 `sidebar` 設定 |
| 內文 | 畫面中間 | 每一頁的 Markdown 檔案 |
| 本頁目錄 | 畫面右邊 | 自動擷取頁面裡的 `##` 與 `###` 標題 |

手機上, 左側選單會收進左上角的「選單」按鈕, 本頁目錄則收進頁首的下拉選單.

## 發布流程

1. 在 `docs/` 資料夾新增或修改 Markdown 檔案.
2. 把修改 push 到 GitHub 的 `main` 分支.
3. GitHub Actions 自動重建網站, 約一至兩分鐘後網站就會更新.

::: tip 不需要自己架伺服器
網站由 GitHub Pages 託管, 不需要租主機, 也不需要維護伺服器.
:::

## 適合放什麼內容

GitHub Pages 的網站是公開的, 任何拿到網址的人都看得到. 因此適合放工具使用說明、公開的技術筆記與教學內容; 含客戶資訊或內部資料的內容, 請改放需要登入的平台.
